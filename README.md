# Red X Quit — Free RedQuits Alternative for macOS

**Red X Quit** is a free, native macOS utility and modern replacement for RedQuits, designed for Apple Silicon Macs.

Looking for a **RedQuits alternative** that doesn't require Rosetta? Red X Quit makes the red **X** close button quit applications instead of leaving them running in the background.

## Features

- Native Apple Silicon support — no Rosetta required.
- Configurable application-closing behavior.
- Launch at Login support.
- Simple, native macOS interface.
- Built-in uninstall utility.
- Free to download and use.
