Red X Quit

A free, modern RedQuits alternative for macOS.

Looking for a RedQuits replacement? Red X Quit makes the red window close button quit applications instead of leaving them running.

Designed for modern Macs, Red X Quit runs natively on Apple Silicon without requiring Rosetta.

Download Red X Quit for macOS

Features

  • Native Apple Silicon support
  • Configurable application-closing behavior
  • Launch at Login support
  • Simple, native macOS interface
  • Built-in uninstall utility
  • Free to download and use

Installation

  1. Download and open RedXQuit.dmg.
  2. Drag RedXQuit.app into Applications.
  3. Launch Red X Quit from Applications.
  4. Grant Accessibility permission when requested.

Red X Quit is signed with an Apple Developer ID certificate and notarized by Apple.
